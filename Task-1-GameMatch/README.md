# 🎮 GameMatch — Personalized Game Finder

## SWYNEX Internship — Task 1

### App Concept

GameMatch is a simple utility app that helps gamers discover the perfect game based on their personal preferences.

The app asks users about their gaming platform, available gaming time, preferred playstyle, and desired gaming experience. It then provides a personalized game or genre recommendation.

## 🎯 Target User

**Primary users:** Casual and regular gamers who have difficulty deciding what game to play.

### User Problem

There are thousands of games across different genres and platforms, making it difficult for users to find a game that matches their preferences and available time.

### Solution

GameMatch uses a short questionnaire to understand the user's gaming preferences and recommends the most suitable game or genre.

## 📱 Screens

1. **Welcome** — Introduces the app and starts the recommendation quiz.
2. **Gaming Preferences** — Collects the user's platform and available gaming time.
3. **Playstyle** — Collects preferred gaming experiences such as action, story, exploration, strategy, racing, and horror.
4. **Your Match** — Displays the best-matching genre and recommended games with match percentages.
5. **Game Details** — Shows information about the selected game and explains why it matches the user.
6. **Saved Games** — Allows users to save recommended games for later.

## 🔀 Navigation Flow

**Welcome → Gaming Preferences → Playstyle → Your Match → Game Details**

From Game Details, users can save a game to **Saved Games** or choose **Try Another** to get another recommendation.

## ♿ Accessibility & Design

- High-contrast dark interface
- Clear and readable typography
- Large touch-friendly controls
- Consistent navigation
- Clear selected and unselected states
- Icons paired with text where useful
- Simple questions to reduce cognitive load

## 🎨 Design

The interface uses a dark gaming-inspired visual style with purple accents, rounded cards, game artwork, and clear visual hierarchy.
