# GameMatch — SWYNEX App Development Internship Task 3 Feature

GameMatch is a mobile-responsive web app built with **HTML, CSS and vanilla JavaScript**.

## Task 3 feature integrated into Gamematch
A complete **My Games** create-and-list flow is included in the main app:
- Add a game with name, platform and genre
- Required-field validation and inline error states
- Duplicate-game validation
- Empty state when the list has no games
- Persistent storage with `localStorage`
- List created games
- Remove games
- Optional notes and session time

## Run locally
Open `index.html` in a modern browser. No framework or build step is required.
